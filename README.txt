PHONE-FRIENDLY DEPLOYMENT
1. Upload this folder to a static web host such as Netlify Drop, Cloudflare Pages or GitHub Pages.
2. Open the resulting URL in Safari on iPhone.
3. Tap Share > Add to Home Screen.

DATA & PRIVACY
The roster and settings are stored locally in the user's browser using localStorage.
No login or server is required.

NOTES
This is an estimate, not payroll advice. Shift times are based on the supplied roster images and older shift sheet.
