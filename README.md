# PTA Pay Calculator — Version 7.1

Agreement-driven update based on the Public Transport Authority / ARTBIU (Transit Officers) Industrial Agreement 2023.

## Included
- Classification selector: Trainee, TO1–TO5, First Class Officer and STO1–STO3.
- Automatic wage-table selection by pay-cycle date for 7 October 2023, 2024 and 2025 rates.
- Optional scheduled annual increments for TO1–TO5 and STO1–STO3, subject to satisfactory review.
- Automatic progression stops at TO5 and STO3; FCO is not automatic.
- Manual rate mode remains available for historical or future rates not contained in the agreement.
- Agreement penalty rules are read-only: weekday 1x, Saturday 1.5x, Sunday 2x, weekday OT 1.84x, weekend OT 2x.
- Annual leave loading enforces the agreement minimum of 20%, while retaining the editable agreed roster loading rate.
- Corrected observed New Year's Day public-holiday handling.
- Existing V7 public-holiday, leave-in-lieu, leave, allowance, saved-pay and backup features retained.

The exact annual-leave loading and some monetary allowances are administratively updated outside the wage table, so those values remain editable.
